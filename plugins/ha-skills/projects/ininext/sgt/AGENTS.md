## 리뷰 가이드라인 (`codex review`)

SGT 는 **에어갭 고객망에 수동 설치되는 제품**이다. 배포는 고객 유지보수 창에서, 롤백·핫픽스는 수주 걸리고, 우리는 고객 로그를 볼 수 없다. 이 전제에서 다음을 우선 본다.

- **호환성 파괴**: 공개 API 경로·응답 계약·helm values 키·env 변수 이름의 변경·축소. 고객이 자체 연동을 만들었을 수 있다.
- **DB 마이그레이션**: admin 은 Flyway. 이미 머지된 `V*.sql` 수정은 체크섬 실패로 **모든 고객사 admin 기동 중단** — 반드시 새 V 파일이어야 한다.
- **helm 의 silent no-op**: 새 values 키가 템플릿에서 안 읽히거나 오타가 조용히 기본값으로 떨어지는 경우.
- **gateway 인증 경로**: 인가 필터와 보호 경로 집합은 두 곳이다. 한쪽만 고치면 미인증 노출.
- **기본값 변경**: 설정 안 한 고객에게 동작이 바뀌는 변경(기본 sink, 기본 포트, 기본 임계값).
- **내부망 위협 모델**: 일반 사용자 JWT 로의 권한 상승, 스코프 검사 누락, 우발적 포트 노출.
- **외부 호출 추가**: 에어갭에서 막힌다. 새 의존성·모델·레지스트리 접근은 오프라인 패키징 확인 없이는 결함.

보고 기준: 코드 경로(파일:라인)로 재현 시나리오를 보여줄 수 있는 것만, 이 변경이 새로 만든 것만. 스타일·추측·기존 문제는 제외한다.
